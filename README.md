# Gravity Bedwars — прототип (three.js)

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173
npm test           # headless-тесты симуляции (движение, порталы, гейзеры, стрельба, блоки, матч)
npm run typecheck
npm run shots      # скриншоты меню, HUD, бота, стройки и магазина в shots/ (нужен запущенный npm run dev и GPU)
```

## Управление
WASD — движение · Пробел/колесо — прыжок (зажать = автобхоп) · мышь — обзор
ЛКМ — огонь · 1 — винтовка · 2 — граната · Q — сменить оружие · R — перезарядка
3 или B — лопатка · ЛКМ — случайная постройка (стена / пол / лестница) · ПКМ — забрать свою · Q/Z/колесо — материал · 1/2 — обратно к оружию
E — магазин (у киоска на крыше базы) · удерживать E у вражеского кристалла — сломать его
Shift+1–6 — гравитация команды (отладка) · N — noclip · K — респавн · T — на центральный остров
G — настройки движения (sv_* в Source units) · P — вкл/выкл рендер порталов

## Карта
- Стиль: солнечный старый европейский город в тёплой дымке (черепичные крыши, пастельные фасады, стеклянные небоскрёбы, парки, каналы).
- Остров = городской квартал 84×84 м (план растянут в стороны в 1,4 раза; высоты прежние). **База команды — небоскрёб** (46 м): на крыше спавн, статуя («кровать»), магазин, генератор.
- Голубой лифт у входа → крыша; фиолетовый гейзер на крыше → центральный остров (песчаник с золотыми рунами и порталами).
- Солнце живёт в системе координат гравитации игрока: у каждой команды «своё» небо.

## Стрельба
- Снаряд получает **гравитацию стрелка** в момент выстрела и сносится **ветром** (детерминированный, меняется каждые 20 с; на снаряд действует только «горизонтальная» для его гравитации часть).
- Винтовка: 160 м/с, 40% гравитации, 60% ветра, 20 урона (×1.6 в голову), 30 патронов. Урон падает с дистанцией: полный до 10 м, дальше линейно до 35% на 45 м и больше (по игрокам и по постройкам).
- Граната: 22 м/с, полная гравитация, отскоки, фитиль 2.5 с, радиус 5.5 м, отбрасывание (рокет-джамп), по себе ×0.35, 3 шт с регенерацией.
- Порталы v1 «съедают» снаряды. Огонь по своим выключен.

## Цель (режим Bedwars против ботов)
- У каждой команды на крыше базы стоит кристалл («кровать»). Пока твой кристалл цел, после смерти ты возрождаешься; без него смерть — выбывание.
- Цель — уничтожить пять других команд: сломать кристалл, затем добить оставшихся бойцов. Каждый кристалл обнесён кольцом блоков высотой 3 м (2 ряда камня + ряд металла): проломи стену оружием или залезь на неё по своим блокам, подойди и удерживай **E** 1,5 с.
- Путь к врагу: гейзер на крыше → центральный куб → портал на грань нужной команды → сойти с края грани и упасть на её остров → голубой лифт на крышу.
- Сверху по центру — состояние команд: ◆ кристалл цел, цифра — сколько бойцов осталось без кристалла, ✕ команда выбыла; слева — медь, кристаллы и время матча. Победа показывает время прохождения.

## Экономика
- Генератор на крыше базы копит **медь**: 1 в секунду, до 48. Собрать — пройти по жёлтой площадке. Можно обирать и чужие генераторы.
- На каждой грани центрального куба генератор **кристаллов**: 1 раз в 15 с, до 4.
- За убийство противника — 3 меди.
- Магазин (E у киоска рядом с кристаллом): дерево ×16 — 8 меди, камень ×12 — 24 меди, металл ×6 — 3 кристалла, аптечка — 10 меди.

## Постройки (лопатка)
- Слот 3 — лопатка. ЛКМ ставит перед тобой **случайную** постройку: стену, пол или лестницу-пандус. Призрак показывает, что выпадет следующим; удерживай ЛКМ, чтобы строить подряд.
- Сетка 4 м по горизонтали, уровень 3 м, выровнена по твоей гравитации. Стена встаёт на ближайшую линию сетки перед тобой, пол и лестница — в клетку за ней. Пол — на уровне ног (мост через пустоту), лестница поднимается от тебя на один уровень. Стоя на своей постройке, следующая встаёт на её уровень, так что лестницы складываются в подъём.
- Постройка стоит 3 единицы материала. HP = HP материала × 2,5: дерево 150, камень 350, металл 750. Тёмные постройки повреждены. В одну ячейку — одна постройка, внутрь игрока или бота поставить нельзя.
- ПКМ возвращает материал только за свои постройки. Чужие постройки и укрепления у кристаллов (блоки 1 м: 60 / 140 / 300 HP) ломаются оружием.
- Это локальный прототип без мультиплеера: соперники — боты.

## Боты
- В каждой вражеской команде по 2 бота: защитник держит крышу у своего кристалла, нападающий через 1–2 минуты идёт на чужую базу (часто — на твою) по тому же пути, что и игрок: гейзер → грань → портал → спуск → лифт.
- Укрепление пробивают винтовкой, кристалл ломают, стоя рядом 1,5 с. Отстреливаются от всех, кого видят в радиусе ~30 м; дома реагируют только на тех, кто подошёл к кристаллу.
- Пока кристалл цел, бот возрождается через 4 с, без него — выбывает. Боты ходят тем же `PlayerSim`, что и игрок, и живут в `src/shared/bots.ts` (готовы для сервера).

## Интерфейс и подсказки
- HUD: слева сверху — чья гравитация и кошелёк с таймером; по центру — кристаллы команд (число живых бойцов, череп у разбитых) и подсказка «что делать дальше»; справа — ветер и лента убийств; снизу — здоровье, слоты 1–3 и патроны.
- Подсказка цели меняется по тому, где ты стоишь: своя крыша → гейзер, грань → порталы, чужая улица → лифт, чужая крыша → пробить стену и держать E.
- Метки кристаллов с расстоянием; если кристалл за кадром, метка прижимается к краю (не заходя на панели). Свой кристалл помечается только издалека (> 30 м).
- Нейтральный стиль: шрифт Inter, текст прямо на картинке с тенью, полупрозрачная подложка только там, где иначе не читается; цвет — только для команд и ресурсов. Иконки — SVG с game-icons.net (красятся через `currentColor`).

## Модели
- Бойцы — анимированный персонаж Kenney Mini Arena (idle / walk / sprint / jump / fall / die, руки держат бластер, отдача при выстреле). Гребень шлема и юбка перекрашиваются в цвет команды шейдером по колонке палитры, броня получает лёгкий оттенок; при попадании модель вспыхивает.
- Винтовка — бластер из Kenney Starter Kit FPS: в руках от первого лица и у ботов. Граната и лопатка — low-poly в той же палитре с акцентом цвета команды.

## База команды
Крыша небоскрёба оформлена в цвет команды: кромка парапета, знамёна по периметру, длинные полотнища на фасадах (видно с улицы и с других островов), круг спавна и название команды на полу. Магазин — лавка с полосатым навесом, прилавком и табличкой. Модели — `PropDef` в карте (`src/shared/map.ts`), рисуются в `render/propView.ts`; под ними невидимые коллайдеры.

## Меню и звуки
Главное меню: запуск / пауза (Esc), управление и настройки громкости, чувствительности и поля зрения. Звуки строительства, разбора, выбора, стрельбы и взрывов синтезируются браузером.

## Структура
- `src/shared/` — код, общий для клиента и будущего сервера:
  - `blocks.ts` — постройки (стена / пол / лестница на сетке гравитации) и блоки укреплений: инвентарь, HP, разрушение
  - `bots.ts` — боты: навигация по структуре карты, обход препятствий, бой, атака кристаллов
  - `match.ts` — правила Bedwars: генераторы, кошелёк, магазин, кристаллы, укрепления, победа/выбывание
  - `constants.ts` — тикрейт 64, константы Source (в метрах)
  - `movement.ts` — Source-движение в локальном базисе гравитации поверх Rapier KCC
  - `sim.ts` — правила мира: гравитация, порталы, лифты/гейзеры, пустота, импульсы
  - `weapons.ts`, `wind.ts`, `combat.ts` — оружие, ветер, снаряды/урон/взрывы
  - `map.ts` — генерация карты (6 кварталов-островов + центральный куб с 18 порталами)
  - `portals.ts`, `physics.ts`, `teams.ts`, `math.ts`
- `src/client/` — рендер, ввод, HUD:
  - `main.ts` — создание и связывание модулей, игровой цикл кадра
  - `playerCombat.ts`, `blockController.ts`, `matchUi.ts`, `keybinds.ts`, `menu.ts`
  - `hud.ts`, `guide.ts` (подсказки цели и метки кристаллов), `icons.ts` + `icons/*.svg`
  - `render/assets.ts` — загрузка glTF-моделей из `public/models/`
  - `render/graphics.ts`, `render/blockView.ts`, `render/generatorView.ts`
  - `render/mapView.ts` — трипланарные текстуры, дома с фасадами и черепицей, небоскрёбы, деревья
  - `render/textures.ts`, `render/sky.ts` — процедурные текстуры, дневное небо с дымкой
  - `render/fx.ts`, `render/viewmodel.ts` — трассеры, гранаты, взрывы, искры, оружие от первого лица
  - `render/portalView.ts`, `render/playerModel.ts`, `render/botView.ts`, `render/gizmo.ts`
- `test/sim.test.ts` — проверки симуляции в Node
- `scripts/shots.ts` — скриншоты через Playwright (headless Chrome рендерит через GPU: ANGLE/Vulkan)
