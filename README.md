# GravWars (Gravity Bedwars) — v0.3.0

Соревновательный 3D-шутер от первого лица в жанре **Bedwars** внутри полого гигантского куба с локальной гравитацией на каждой грани, Source-подобным движением, процедурными городами, умными ботами, ретро-пиксельным рендером и P2P-мультиплеером поверх WebRTC.

## Стек

- **Рендер:** Three.js (`WebGLRenderer`, `EffectComposer`, кастомные шейдеры `RetroPass` / `XRayPass` / `OverlayPass`, interior mapping, процедурные модели и текстуры)
- **Физика:** Rapier3D WASM (`@dimforge/rapier3d-compat`, KCC-контроллер персонажа, динамические ящики/бочки, лучевые тесты)
- **Мультиплеер:** WebRTC P2P через PeerJS (Host-Authoritative + Client-Side Prediction `PMove` + Entity Interpolation)
- **Сборка и тесты:** TypeScript 7 (`strict: true`), Vite 8 (Rolldown), `tsx`, Playwright

## Запуск и тесты

```bash
npm install
npm run dev        # локальный сервер разработки http://localhost:5173
npm run build      # production-сборка в dist/
npm run preview    # предпросмотр production-сборки
npm run typecheck  # проверка типов (tsc --noEmit)
npm test           # быстрые headless-тесты симуляции (движение, бой, мир, ИИ, сеть/валидация)
npm run test:sim   # 15-минутный soak-тест полного матча ботов и NPC
npm run test:e2e   # E2E в Chromium: соло-запуск, стройка и двухвкладочный P2P-матч (нужен npm run build)
npm run test:all   # последовательный прогон всех тестовых уровней
npm run shots      # генерация скриншотов через Playwright (нужен запущенный dev-сервер и GPU)
```

## Управление

- **Движение:** `WASD` — ходьба · `Shift` — спринт (×1,65, 8 с выносливости) · `Ctrl`/`C` — присед (бесшумный, снижает разброс ×0,65) · `Пробел` — прыжок (короткий ~1,3 м, зажатый до ~3,3 м, автобхоп; в воздухе при наличии ранца — полёт) · колесо мыши — прыжок
- **Обзор и прицел:** мышь — обзор · `X` (или `ПКМ` с арбалетом) — плавный 2× зум
- **Оружие и пояс:** `1–9` — слот пояса (повтор — убрать в карман, пустые руки = кулаки) · `Q` — следующий слот · `R` — перезарядка (попадание в зелёную зону кольца — мгновенная активная перезарядка) · `V` — пинок ногой · `ПКМ` с револьвером — прокрутка барабана на пальце
- **Действия:** `ЛКМ` — огонь / удар / зарядка арбалета / зажим револьвера / бросок гранаты / постройка / крюк-кошка / заброс удочки / удержание 1 с — съесть яблоко или вылечиться · `G` — бросить предмет из руки · `F` — взять яблоко · `E` — магазин у прилавка / подобрать предмет / открыть или закрыть командную дверь и люк (удержание `E` — подобрать всё в радиусе спереди)
- **Строительство:** `B` — режим строительства · держать `Q` — круговое меню форм (блок 1×1×1 / стена / пол / лестница) · `R` — вариант (сплошная / проём / дверь-люк) · `Z` или колесо — материал · `ЛКМ` — поставить · `ПКМ` — разобрать свою постройку
- **Интерфейс и чат:** `I` — инвентарь (пояс 9 слотов + рюкзак 9 ячеек, характеристики, выброс) · `Tab` (держать) — таблица счёта и задачи союзных ботов · `T` — внутриигровой чат · `F10` — скачать журнал ошибок (`game-errors.txt`) · `Esc` — меню (мир на паузе продолжает жить)
- **Отладка:** `` ` `` (тильда) — панель `sv_*`-параметров движения (`lil-gui`) · `Shift+1–6` стоя на месте — сменить гравитацию грани · `N` — noclip · `K` — респавн · `Y` — телепорт на нейтральную грань

## Режимы игры и лобби

Лобби (`src/shared/lobby.ts`, `src/client/lobby.ts`) поддерживает до **5 команд** (красные, синие, зелёные, жёлтые, фиолетовые), индивидуальную сложность каждого бота (`лёгкая` / `обычная` / `сложная`), бесконечные деньги и **экстрим-настройки** (до 10 мест в команде и настраиваемые множители: награда, урон, HP игроков, HP кристаллов, HP ящиков, HP построек, цены в `$` и кристаллах).

- **Классика (`standard`):** 6 внутренних граней куба, до 5 играющих команд, остальные грани — нейтральные города с рынками и генераторами кристаллов.
- **Дуэль (`duel`):** 4 острова (2 противостоящие базы + 2 нейтральные грани по бокам) и 4 моста.
- **Схватка (`skirmish`):** 2 близких отзеркаленных острова (3 случайных тайла на сторону), бесплатное оружие в магазине, +1 дерево/с внутри своей базы, `$25` за убийство и убранное солнце.
- **Песочница (`sandbox`):** одиночный режим без ограничений на количество команд.

## Мир, гравитация и движение

- **Кубический мегаполис (`src/shared/mapgen/`):** ребро куба 252 м (`cubeHalf = 126 м`), каждая грань — город 180×180 м (`faceHalf = 90 м`, 5×5 тайлов по 36 м) с пропастью до ребра и бездной (`voidMargin = 20 м`).
- **Случайные кварталы:** небоскрёбы, офисы, жилые дома, парки, пруды с мостами, многоуровневые парковки, стройки, площади, рынки, **музей** (2 входа, скелет и круглое отверстие в потолке), ямы, трубопроводы, бары, магазины, баскетбольные площадки и фонтаны; на дорогах встречаются выбоины с гарантированной связностью дорожного графа.
- **Гравитация поверхностей (`src/shared/gravity.ts`):** притягивают только земля граней и построенные плиты «Пол». Мосты через рёбра строятся вручную игроками и ботами поверх единой сетки 6 м (высота уровня 3 м).
- **Source-движение (`src/shared/movement.ts`, 64 Гц):** бхоп, air-strafe (`airAccelerate = 12`, `airSpeedCap = 30 u/s`), ramp surfing (`groundCos = 0.68`), coyote-time, прыжок переменной высоты, wall-slide для безопасного спуска со стен, урон от падения, плюх в воду без урона.

## Бой, оружие и снаряжение

- **Баллистика (`src/shared/combat.ts`, `src/shared/weapons.ts`):** пули наследуют гравитацию стрелка, сносятся ветром, теряют энергию от сопротивления воздуха, пробивают тонкие деревянные стены и рикошетят от твёрдых поверхностей под острым углом. По живым целям действует масштабирование урона (`DAMAGE_SCALE = 1/3`, кроме оружия с флагом `raw`), по постройкам — отдельный `blockDamage`.
- **Оружие:**
  - **Кулаки** (старт): ближний сплеш с отталкиванием.
  - **Пинок (`V`):** 10 урона, сильный толчок людей, ящиков и бочек (перезарядка 2 с при попадании, 0,1 с при промахе).
  - **Пистолет ($20):** магазин 15, самозарядный.
  - **Револьвер ($30):** магазин 6, выстрел по зажатию ЛКМ (`0,22 с` взвод), 25 raw-урона + **цепной рикошет** по живым целям на 20 урона в радиусе 28 м; ПКМ — вращение барабана.
  - **Дробовик ($35):** 8 дробин, магазин 6, помповый с поштучной прерываемой дозарядкой.
  - **Автомат ($40):** магазин 30, ~650 выстр./мин, пробивает деревянные стены.
  - **Арбалет ($75):** удержание ЛКМ заряжает болт до уровней 0–3 (`5 / 10 / 25 / 60` raw-урона, болты уровней 2–3 пробивают цели насквозь), ПКМ — 2× зум.
  - **Ракетница (5 крист.):** взрыв радиусом `6,75 м`, `90` raw-урона (×0,4 по себе — рокет-джамп).
  - **Гранаты ×2 ($10):** фитиль `2,5 с`, радиус `5,5 м`, индикатор-кольцо на экране рядом с гранатой.
- **Снаряжение и утилиты:**
  - **Удочка ($5):** рыбалка в прудах и фонтанах (`src/shared/fishing.ts`).
  - **Крюк-кошка ($9):** дальность `35 м`, магнит `0,25 м`, подтягивание до `24 м/с`.
  - **Реактивный ранец (5 крист.):** полёт по удержанию `Пробел` в воздухе, тратит патроны как топливо, перегревается и взрывается через `12 с` непрерывного полёта.
  - **Бронежилет (5 крист.):** при смертельном уроне разрушается и мгновенно восстанавливает 50% максимального HP.
  - **Аптечка ($8):** до 3 шт., полное восстановление здоровья.
- **База и респавн (`src/shared/match.ts`):**
  - Двухстадийный **кристалл**: `250 HP` на стадию (`BED_HP = 250`), регенерация `2,5 HP/с` через `15 с` без урона, урон проходит только с дистанции ≤ 5 м. После слома 1-й стадии кристалл на `10 с` закрывается щитом и детонирует в радиусе `10 м` (оглушение врагов на `3,5 с` и мгновенное воскрешение павших союзников).
  - Зона своего живого кристалла (`< 8,5 м`): пассивное лечение `+2 HP/с` и автопополнение боезапаса.
  - Респавн после смерти — `8 с` (`RESPAWN_DELAY = 8`), защита после спавна — `3 с`. При смерти выпадают предметы из карманов и половина денег; оружие, инструменты и блоки сохраняются.

## Боты и городская экосистема

- **ИИ ботов (`src/shared/bots.ts`, `src/shared/bots/*`):** работают через тот же `PlayerSim` и `Economy`, что и игрок. Зарабатывают (лут, рыбалка, охота на бандитов, сбор кристаллов), закупаются по списку приоритетов (`botShop.ts`), защищают и чинят укрепления, сносят вражеские стены, строят мосты через рёбра, собираются в рейды и совершают правдоподобные ошибки в зависимости от сложности.
- **Жители и трафик (`src/shared/npcs.ts`, `src/shared/npcs/*`):**
  - **Бродяги:** гуляют, оставляют бутылки, дерутся между собой и с теми, кто их задел.
  - **Банды:** держат дальние перекрёстки, реагируют на зрение/шум/присед (`?` / `!`), телеграфируют очереди вспышкой и замиранием прицела, бросают гранаты навесом, роняют деньги.
  - **Дорожный трафик (`cars.ts`):** машины курсируют по улицам, объезжают препятствия, исчезают в конце маршрута; при обстреле включают сигнализацию, могут бежать или идти на таран со взрывом.

## Сетевая игра (WebRTC P2P)

- **Транспорт (`src/client/net/p2p.ts`):** PeerJS поверх WebRTC без выделенного сервера (короткий 5-символьный код комнаты и ссылки-приглашения `?room=CODE`). Используется **двухканальная схема**:
  - основной `reliable: true` DataChannel — жизненный цикл подключения, лобби, чат, надёжные боевые/строительные события и критичные дельты мира;
  - дополнительный `reliable: false` (`label: 'fast'`) DataChannel — высокочастотные вводы (64 Гц) и рутинные снапшоты мира (25 Гц) с защитой от bufferbloat и автоматическим fallback на основной канал.
- **Предсказание и синхронизация:**
  - GoldSrc/Source-модель **`UserCommand` / `PMove`** (`src/shared/net/pmove.ts`, `src/client/net/pmoveClient.ts`): клиент предсказывает движение локально и при расхождении с хостом реконсилирует и переигрывает неподтверждённые команды.
  - Удалённые игроки интерполируются с буфером 100 мс (`src/client/net/remotePlayerManager.ts`).
  - Снапшоты квантизируются (`src/shared/net/snapshot.ts`, `src/client/net/netHostSnapshot.ts`): NPC и машины обновляются адаптивно по дистанции до наблюдателей (12,5 Гц рядом, ~4,2 Гц вдали, 25 Гц в бою/таране, подавление повторных мёртвых состояний и полный resync раз в секунду).
- **Античит и валидация (`src/shared/net/validate.ts`, `src/client/net/netHostActions.ts`):** авторитетный хост проверяет NaN/Infinity, близость origin выстрелов/пинков/крюка к позиции игрока, габариты и стоимость построек, дистанцию и частоту рыбалки, а также ограничивает частоту действий через token-bucket `RateLimiter`.

## Графика, звук и диагностика

- **Ретро-рендер (`src/client/render/graphics.ts`):** отрисовка в настраиваемом низком разрешении (360/480/720 строк или нативно), `UnrealBloomPass`, `XRayPass` (контурная подсветка союзников/врагов/кристаллов за стенами), `OverlayPass` (руки от 1-го лица в ту же пиксельную сетку), `RetroPass` (целочисленное увеличение + 4×4 Bayer dithering), `rooms.ts` (interior mapping комнат за окнами), `water.ts` (аналитическая рябь и Френель), запекание процедурных скелетов с 2-костным IK (`bake.ts`, `human.ts`, `playerModel.ts`).
- **Процедурный звук (`audio.ts`, `music.ts`, `ambience.ts`):** 100% WebAudio-синтез без аудиофайлов — выстрелы с задержкой скорости звука, стадии перезарядки, пространственный эмбиент по биомам и процедурная музыка.
- **Жизненный цикл и диагностика:**
  - Инкапсулированный `MatchSession` (`src/client/matchSession.ts`) с явным `dispose()` (освобождение мира Rapier, WebGL-буферов, слушателей, `lil-gui` и HUD) — выход в главное меню и перезапуск матча происходят **in-process без `location.reload()`**.
  - `GameLogger` (`src/client/logger.ts`) с off-thread Web Worker watchdog для обнаружения фризов главного потока (>1,8 с), записью спайков кадра, скачиванием `game-errors.txt` по `F10` и dev-middleware `/__log` в `vite.config.ts`.
