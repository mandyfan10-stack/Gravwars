# Gravity Bedwars — прототип (three.js)

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173
npm test           # headless-тесты симуляции (движение, гравитация поверхностей, мосты, стрельба, блоки, матч)
npm run typecheck
npm run shots      # скриншоты: меню, HUD, бот, продавец, магазин, кулаки, стройка, рыбалка, яблоки (нужен запущенный npm run dev и GPU)
```

## Управление
WASD — движение · Shift — тихий шаг · Ctrl/C — присесть · Пробел/колесо — прыжок (зажать = автобхоп) · мышь — обзор
ЛКМ — удар / огонь · 1 — кулаки · 2 — пистолет · 3 — автомат · 4 — гранаты · Q — следующее оружие · R — перезарядка
5 или B — строительство · ЛКМ — случайная постройка (стена / пол / лестница) · ПКМ — забрать свою · Q/Z/колесо — материал
6 — удочка · ЛКМ — заброс в пруд, потом подсечка
E — подобрать яблоко / бутылку / деньги · магазин (у прилавка на крыше базы; Q или Tab — вкладка «Купить» / «Продать», цифры — выбрать) · удерживать E у вражеского кристалла — сломать его
F — съесть яблоко
Tab (держать) — счёт матча: команды, кристаллы, бойцы, убийства и твоя статистика
В слотах показывается только купленное.
Shift+1–4 — гравитация команды (отладка) · N — noclip · K — респавн · T — на центральную площадь
G — настройки движения (sv_* в Source units)

## Карта
- Стиль: солнечный старый европейский город в тёплой дымке (черепичные крыши, пастельные фасады, стеклянные небоскрёбы, парки, каналы).
- Остров базы — городской квартал 5×5 тайлов по 32 м (160×160 м), на расстоянии 432 м от центра. **База — зал** 24×24 м в тайле за площадью: внутри кристалл с укреплением, спавн, магазин; две двери на улицу (спереди и сзади) и два пандуса на крышу.
- **Центр** — большой плоский нейтральный город 7×7 тайлов (224×224 м): бульвары крестом (по ним идут мосты), площадь с 4 генераторами кристаллов, 4 рынка с нейтральными продавцами, музеи, парки с прудами, бандиты и бродяги.
- **Гравитация — к ближайшей поверхности.** Тянут только «плиты»: верх острова, верх центра, опора моста и любая постройка «Пол». Подойди вплотную к поверхности другой гравитации — мир повернётся, она станет полом. Прыжки и падения гравитацию не меняют: сорвался с моста — пустота.
- **Опора моста** — бетонная полоса посреди площади перед залом, стоит «стеной» на 20 м в сторону центра; её грань ровная для гравитации центра. С её конца строят **мост** плитами «Пол» (над пустотой плита стоит 1 материал вместо 3) — 75 плит до края центра. Мосты всех команд идут по одним линиям (x = ±2, y = ±2), так что мост, построенный с одной стороны, годится и в обратную.
- Острова создаются только для команд, в которых кто-то играет (`generateMap(seed, spawnTeam, teams)`).
- Всё стоит на сетке строительства 4 м: тайлы 32 м, кварталы 24 м, дома шириной 4/8 м, офисы 8/16 м.
- Солнце живёт в системе координат гравитации игрока: у каждой команды «своё» небо.

## Стрельба
- Снаряд получает **гравитацию стрелка** в момент выстрела и сносится **ветром** (детерминированный, меняется каждые 20 с; на снаряд действует только «горизонтальная» для его гравитации часть).
- **Баллистика пуль:** реальная начальная скорость, полная гравитация и квадратичное сопротивление воздуха относительно ветра. Урон пропорционален оставшейся кинетической энергии, (v/v₀)², но не меньше 30 %. На 100 м пуля автомата теряет ~8 % скорости и опускается на ~0,15 м, пуля пистолета — ~17 % и ~1 м.
- **Пробитие:** пуля проходит стену, если после неё остаётся больше 120 м/с. Потеря скорости на метр: дерево 1600 м/с, камень 9000, металл 22000; бетон карты не пробивается. Автомат пробивает деревянную стену-постройку (0,25 м) с потерей урона, пистолет застревает в ней.
- **Рикошет:** пуля, попавшая по твёрдой поверхности (бетон, камень, металл) под углом меньше ~15°, отскакивает один раз с 60 % скорости.
- **Разброс и отдача:** первый выстрел почти точный, в очереди разброс растёт, на бегу и в прыжке — сильнее. Отдача уводит прицел вверх, после 4–5 патронов очереди ещё и в стороны. Отпустишь спуск — оружие само возвращается на ~60 % подброса.
- **Время убийства** — 4–6 с в реальном бою (попадает ~40 % пуль); если попадать всеми, около 1,5 с. Урон по постройкам задан отдельно (`blockDamage`) и не менялся: стены держатся столько же.
- Кулаки: ближний бой (2,3 м), 10 урона (×1,25 в голову), без патронов, лёгкий толчок; по постройкам — 6.
- **Пистолет** (9 мм, самозарядный): 360 м/с, 9 урона (×2 в голову; по постройкам 26), магазин 15, темп до ~8 выстрелов/с (выстрел на нажатие).
- **Автомат** (5,45 мм): 880 м/с, 7 урона (×2 в голову; по постройкам 28), магазин 30, ~650 выстрелов/мин.
- **Перезарядка (R):** при неполном магазине патрон остаётся в патроннике — 15+1 / 30+1, быстрее (1,5 / 2,1 с). С пустым магазином дольше (1,9 / 2,6 с): ещё нужно передёрнуть затвор. У пистолета на пустом магазине затвор встаёт на задержку. Звуки по стадиям: защёлка, магазин вынут, магазин встал, затвор. На пустом магазине без запаса — сухой щелчок.
- Звук выстрела: хлопок и «треск» пули; дальние выстрелы тише, глуше и приходят с задержкой по скорости звука. Попадания звучат по материалу, рикошет — свистом.
- Модели оружия процедурные (`render/guns.ts`): пистолет с полимерной рамкой, автомат с деревянным цевьём и прикладом, изогнутым магазином. Магазин и затвор анимируются при перезарядке.
- Патроны покупаются отдельно для пистолета и автомата и лежат в запасе; R перекладывает их в магазин. Пустой магазин без запаса не стреляет.
- Граната: 22 м/с, до 45 урона (по постройкам 75), полная гравитация, отскоки, фитиль 2.5 с, радиус 5.5 м, отбрасывание (рокет-джамп), по себе ×0.35. Покупаются по 2, с собой до 4.
- Огонь по своим выключен.

## Цель (режим Bedwars против ботов)
- У каждой команды на крыше базы стоит кристалл («кровать»). Пока твой кристалл цел, после смерти ты возрождаешься; без него смерть — выбывание.
- Цель — уничтожить три другие команды: сломать кристалл, затем добить оставшихся бойцов. Каждый кристалл обнесён кольцом блоков высотой 3 м (2 ряда камня + ряд металла): проломи стену оружием или залезь на неё по своим блокам, подойди и удерживай **E** 1,5 с.
- Путь к врагу: из зала на площадь → в опору моста → по мосту (строишь сам) → через центр → по мосту врага → в его опору → на его остров → в зал через дверь или с крыши.
- Сверху по центру — состояние команд: ◆ кристалл цел, цифра — сколько бойцов осталось без кристалла, ✕ команда выбыла; слева — деньги, кристаллы и время матча. Победа показывает время прохождения.

## Экономика
- Старт с пустыми карманами и кулаками. Денег без дела не прибавляется: генератора на базе больше нет.
- **Яблоки** лежат под деревьями (по одному под каждым, возвращаются через 45 с). E — подобрать, F — съесть (+25 HP).
- **Бутылки** в основном оставляют бродяги: допив, бросают пустую на улице (лежит 3 минуты, не больше 18 на остров). Ещё по 4 случайных бутылки на остров появляются сами (взятая — через 90 с в другом месте).
- **Рыба** ловится удочкой в пруду парка: ЛКМ по воде — заброс, 2,5–6 с ожидания, поклёвка запускает шкалу — метка проходит её один раз, ЛКМ в зелёной зоне = рыба. Рано или мимо — рыба уходит. Отойдёшь дальше 11 м — леска сматывается.
- Продажа (вкладка «Продать» в магазине): бутылка 1, яблоко 2, рыба 5; «Продать всё». Магазин открывается на этой вкладке, если есть что продать.
- **Лестница покупок** — следующая ступень открывается после предыдущей: удочка (6) → инструмент строителя (15, +12 дерева) → пистолет (25) → автомат (55) → гранаты ×2 (18) → камень ×12 (16, открывает и металл ×6 за 3 кристалла). Дерево ×16 (6) продаётся с инструментом. Следующая закрытая ступень видна в магазине серой.
- Патроны: пистолет ×15 (магазин) — 4, автомат ×30 — 8. Аптечка — 10.
- Купленное оружие и патроны остаются после смерти.
- На центральной площади — 4 генератора **кристаллов**: 1 раз в 15 с, до 4. За убийство противника — 3 денег. Купить можно у своего продавца в зале и у нейтральных на рынках центра.
- Продавец за прилавком — та же модель бойца в тёмном костюме, тёмных очках и с аурой цвета команды.

## Жители города
На всех островах (`src/shared/npcs.ts`); в центре вдвое больше бродяг и банда побольше.
- **Бродяги** (5 на остров) — грязная одежда, белые глаза. Слоняются по улицам, время от времени останавливаются выпить и бросают пустую бутылку. Задиристые: иногда дерутся друг с другом, бьют кулаками всех, кто подошёл слишком близко или задел их. Слабые (60 HP), после смерти появляются снова через 35 с; иногда роняют бутылку.
- **Банды** (3 бандита с пистолетами на остров, 5 в центре) держат свой квартал — самый дальний от опоры моста / центральной площади. Стреляют короткими очередями, но только по тем, кого заметили. Подстреленный бандит поднимает всю банду. Потеряв цель, обыскивают место, где видели её в последний раз, и возвращаются. Каждый роняет 4–9 денег (подобрать — E), банда возвращается через минуту. С кулаками к ним лучше не лезть, с пистолетом — можно.
- **Скрытность.** У жителей есть угол и дальность обзора (бандиты видят дальше, ~24 м), стены и машины закрывают вид. Попав в поле зрения, ты не сразу становишься целью: подозрение растёт тем быстрее, чем ближе ты и чем быстрее двигаешься (бег ×1, тихий шаг на Shift ×0,5, стоишь ×0,35; вплотную — втрое быстрее), и спадает, когда тебя не видно. Над головой жителя: **?** с полоской — замечает, **!** — идёт на тебя. Бег слышно за 7 м даже со спины, удар — за 9 м, выстрел — за 38 м, взрыв — за 45 м: услышав, житель идёт проверить.
- Боты не трогают жителей, пока на них не напали или не подошли вплотную. За убийство жителя наград за фраг нет — только то, что выпало.
- Жители, рядом с которыми (60 м) нет ни игрока, ни бота, симулируются в 8 раз реже, так что 47 жителей почти ничего не стоят.

## Постройки (лопатка)
- Слот 3 — лопатка. ЛКМ ставит перед тобой **случайную** постройку: стену, пол или лестницу-пандус. Призрак показывает, что выпадет следующим; удерживай ЛКМ, чтобы строить подряд.
- Сетка 4 м по горизонтали, уровень 3 м, выровнена по твоей гравитации. Стена встаёт на ближайшую линию сетки перед тобой, пол и лестница — в клетку за ней. Пол — на уровне ног (мост через пустоту), лестница поднимается от тебя на один уровень. Стоя на своей постройке, следующая встаёт на её уровень, так что лестницы складываются в подъём.
- Постройка стоит 3 единицы материала. HP = HP материала × 2,5: дерево 300, камень 1050, металл 3375 (у блоков укреплений 1 м — 120 / 420 / 1350: дерево +100 %, камень +200 %, металл +350 % к прежним). Повреждённые постройки темнеют и покрываются трещинами — чем меньше HP, тем их больше. В одну ячейку — одна постройка, внутрь игрока или бота поставить нельзя.
- ПКМ возвращает материал только за свои постройки. Чужие постройки и укрепления у кристаллов (блоки 1 м: 60 / 140 / 300 HP) ломаются оружием.
- Это локальный прототип без мультиплеера: соперники — боты.

## Боты
- В каждой вражеской команде по 2 бота: защитник держит зал у своего кристалла, нападающий через 1–2 минуты идёт на чужую базу (часто — на твою) по тому же пути, что и игрок, и сам кладёт плиты моста там, где их ещё нет.
- Упрощённая экономика: боты не рыбачат и не ходят в магазин. Как и игрок, начинают с кулаками (бьют только вплотную), на 20-й секунде матча получают пистолет, на 150-й — автомат; запас патронов бесконечный.
- Укрепление пробивают оружием, кристалл ломают, стоя рядом 1,5 с. Отстреливаются от всех, кого видят в радиусе ~30 м; дома реагируют только на тех, кто подошёл к кристаллу.
- Пока кристалл цел, бот возрождается через 4 с, без него — выбывает. Боты ходят тем же `PlayerSim`, что и игрок, и живут в `src/shared/bots.ts` (готовы для сервера).

## Интерфейс и подсказки
- HUD: слева сверху — чья гравитация и кошелёк с таймером; по центру — кристаллы команд (число живых бойцов, череп у разбитых) и подсказка «что делать дальше»; справа — ветер и лента убийств; снизу — здоровье, над ним карманы (бутылки, яблоки, рыба, патроны к купленному оружию), слоты купленного и патроны «магазин / запас»; во время поклёвки — шкала подсечки.
- Прицел: точка, а с оружием — четыре риски на текущем разбросе: расходятся в очереди, на бегу и в прыжке, сходятся в приседе.
- Подсказка цели меняется по тому, где ты стоишь: свой зал → к опоре, мост → держи пол, центр → генераторы и рынки, чужая улица → двери зала, чужой зал → пробить стену и держать E.
- Метки кристаллов с расстоянием; если кристалл за кадром, метка прижимается к краю (не заходя на панели). Свой кристалл помечается только издалека (> 30 м).
- Нейтральный стиль: шрифт Inter, текст прямо на картинке с тенью, полупрозрачная подложка только там, где иначе не читается; цвет — только для команд и ресурсов. Иконки — SVG с game-icons.net (красятся через `currentColor`).

## Модели
- Бойцы — анимированный персонаж Kenney Mini Arena (idle / walk / sprint / jump / fall / die, руки держат бластер, отдача при выстреле). Гребень шлема и юбка перекрашиваются в цвет команды шейдером по колонке палитры, броня получает лёгкий оттенок; при попадании модель вспыхивает.
- Автомат и пистолет — бластеры из Kenney Starter Kit FPS (большой и малый): в руках от первого лица и у ботов. Без оружия боец держит руки свободно и бьёт правой. Граната, лопатка, удочка и кулаки от первого лица — low-poly в той же палитре с акцентом цвета команды.
- Продавец: модель бойца с тёмной «формой», очки на кости головы, аура — аддитивный цилиндр с градиентом, кольцо на полу и тусклый свет цвета команды.

## База команды
Зал из бетона с ленточным остеклением; цвет команды — светящийся карниз, полоса над дверями, название над входами, кромка парапета на крыше, знамёна у входа, круг спавна и название на полу. Продавцы в центре — нейтрального стального цвета. Магазин — лавка с полосатым навесом, прилавком, табличкой и продавцом на ступеньке за стойкой. Модели — `PropDef` в карте (`src/shared/map.ts`), рисуются в `render/propView.ts`; под ними невидимые коллайдеры.

## Меню и звуки
Главное меню: запуск / пауза (Esc), управление и настройки громкости, чувствительности, поля зрения, текстур (пиксельные — чёткие тексели, по умолчанию; сглаженные) и сложности ботов. Настройки сохраняются в `localStorage` (`src/client/settings.ts`) и переживают перезагрузку.
- **Сложность ботов** (лёгкая / обычная / сложная, `applyDifficulty` в `src/shared/bots.ts`): реакция, разброс, очереди, дальность обзора, когда нападают и как часто идут на тебя, когда получают пистолет и автомат. Ботов в команде всегда по 2. До первого старта меняется сразу, в начатом матче — со следующего.
- **Пауза** показывает ход матча: таблицу команд и твою статистику (время, убийства и в голову, смерти, сломанные тобой кристаллы, убитые жители, заработанные деньги — `src/client/stats.ts`).
- **Конец матча:** после баннера победы / поражения через 2,5 с открывается меню с итогами. Главная кнопка — «Новый матч» (перезагрузка страницы — честный полный сброс), «Осмотреться» возвращает в мир. В паузе «Новый матч» тоже есть, но просит нажать второй раз.

Все звуки синтезируются браузером, без файлов:
- шаги (на тихом шаге — тише, в приседе — беззвучно), приземление по силе удара;
- окружение по месту: ветер (сильнее вне города и при быстром полёте, с порывами), низкий гул города у домов, птицы у деревьев, вода у пруда.

## Движение
- Source-движение (бхоп, стрейфы, сёрф) на Rapier KCC в базисе своей гравитации.
- Присед (Ctrl / C): скорость 34 %, беззвучно для жителей и хуже заметен им (×0,6), разброс ×0,65, глаза на 0,5 м ниже. Хитбокс пока прежний.
- «Койот-тайм»: прыжок срабатывает ещё 0,1 с после того, как сошёл с края.
- Камера: плавное опускание в приседе, просадка на пружине при приземлении.

## Окна: комнаты за стеклом
Шейдер interior mapping (`render/rooms.ts`) для фасадов домов, стеклянных башен и офисов: в маске стекла луч взгляда трассируется внутри «коробки» комнаты (задняя и боковые стены, пол, потолок) в касательном базисе стены, построенном из экранных производных. У каждой комнаты свои цвета по хешу ячейки: обои, пол, свет включён или нет (тёплая лампа), иногда шторы, картина и мебель у задней стены. У башен и офисов комнаты нейтральные, вдали стекло больше отражает. Без дополнительной геометрии.

## Структура
- `src/shared/` — код, общий для клиента и будущего сервера:
  - `blocks.ts` — постройки (стена / пол / лестница на сетке гравитации) и блоки укреплений: инвентарь, HP, разрушение
  - `bots.ts` — боты: навигация по структуре карты, обход препятствий, бой, атака кристаллов
  - `match.ts` — правила Bedwars: генераторы кристаллов, кошелёк, кристаллы, укрепления, победа/выбывание
  - `economy.ts` — предметы (бутылки, яблоки, рыба), яблоки/бутылки на карте, лестница покупок, магазин, продажа
  - `npcs.ts` — жители города: бродяги и банды, обзор, слух и подозрение, маршруты по дорогам
  - `fishing.ts` — рыбалка: заброс, ожидание, поклёвка и шкала подсечки
  - `constants.ts` — тикрейт 64, константы Source (в метрах)
  - `movement.ts` — Source-движение в локальном базисе гравитации поверх Rapier KCC
  - `sim.ts` — правила мира: смена гравитации по поверхностям (`gravity.ts`), пустота, импульсы
  - `weapons.ts`, `wind.ts`, `combat.ts` — оружие, ветер, снаряды/урон/взрывы
  - `map.ts` — генерация карты (острова баз с залами и опорами мостов, плоский город в центре, плиты гравитации, линии мостов)
  - `portals.ts`, `physics.ts`, `teams.ts`, `math.ts`
- `src/client/` — рендер, ввод, HUD:
  - `main.ts` — создание и связывание модулей, игровой цикл кадра
  - `playerCombat.ts`, `blockController.ts`, `matchUi.ts` (магазин, кошелёк), `pockets.ts` (подбор, еда, удочка, карманы), `keybinds.ts`, `menu.ts`
  - `hud.ts`, `guide.ts` (подсказки цели и метки кристаллов), `icons.ts` + `icons/*.svg`
  - `render/assets.ts` — загрузка glTF-моделей из `public/models/`
  - `render/graphics.ts`, `render/blockView.ts`, `render/generatorView.ts`
  - `render/mapView.ts` — трипланарные текстуры, дома с фасадами и черепицей, небоскрёбы, деревья
  - `render/textures.ts`, `render/sky.ts` — процедурные текстуры, дневное небо с дымкой
  - `render/fx.ts`, `render/viewmodel.ts` — трассеры, гранаты, взрывы, искры, оружие от первого лица
  - `render/portalView.ts`, `render/playerModel.ts`, `render/botView.ts`, `render/gizmo.ts`
  - `render/rooms.ts` — комнаты за окнами (interior mapping); `render/texFilter.ts` — пиксельная / сглаженная фильтрация текстур
  - `render/guns.ts` — модели пистолета и автомата (вид от первого лица и в руках персонажей)
  - `render/keeperView.ts` — продавцы; `render/pickupView.ts` — яблоки, бутылки, деньги, поплавок и леска
  - `render/npcView.ts` — бродяги и бандиты, метки «?» / «!»
- `test/sim.test.ts` — проверки симуляции в Node
- `scripts/shots.ts` — скриншоты через Playwright (headless Chrome рендерит через GPU: ANGLE/Vulkan)
